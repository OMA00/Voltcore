Quickstart

1. Get your API key

Generate an API key via Telegram:

/newkey my-first-key

Or via the API (admin only):

curl -X POST https://voltcore.africa/api/keys \\
  -H "x-api-key: ADMIN_KEY" \\
  -H "Content-Type: application/json" \\
  -d '{"userId":"USER_ID","name":"my-app"}'

2. Make your first request

curl -X POST https://voltcore.africa/api/v1/chat/completions \\
  -H "x-api-key: vck_YOUR_KEY" \\
  -H "Content-Type: application/json" \\
  -d '{
    "model": "micro-gpt",
    "prompt": "Write a product description for a Lagos restaurant.",
    "max_tokens": 500
  }'

3. Install the SDK (coming soon)

npm install @voltcore/sdk

Core Endpoints

GET /api/v1/health

Check API status

GET /api/v1/models

List available models and pricing

POST /api/v1/chat/completions

Run inference (prompt or messages)

GET /api/v1/usage

Get your usage stats and cost

SDK (Beta)

import VoltCore from '@voltcore/sdk'

const client = new VoltCore({ apiKey: 'vck_YOUR_KEY' })

const result = await client.chat({
  model: 'micro-gpt',
  prompt: 'Summarise: ...',
  maxTokens: 500
})

console.log(result.response)
console.log(result.costNGN)
